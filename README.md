
 # Suman Suiwal — Weather App

A responsive weather application built as part of the internSpark JavaScript Mini Project (Task 2).

## 🔗 Live Demo

https://sumansuiwal992.github.io/responsive-weather-app/

## 📌 About

A mini interactive JavaScript app that fetches real-time weather data for any city (or the user's current location) using the OpenWeatherMap API, featuring a clean dark-themed UI built with DOM manipulation.

## ✨ Features

- Search weather by city name
- "Use My Current Location" button using the Geolocation API
- Displays temperature, feels-like temperature, and weather condition
- Shows humidity, wind speed, visibility, and min/max temperature
- Recent searches shown as quick-access chips
- Dark / Light theme toggle
- Error handling for invalid city names
- Fully responsive layout (mobile, tablet, desktop)

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla, ES6+)
- OpenWeatherMap API
- Google Fonts (Poppins)

## 🚀 Run Locally

1. Clone the repository

   git clone https://github.com/sumansuiwal992/weather-app.git
 
2. Open `script.js` and replace the placeholder with your own OpenWeatherMap API key:
   ```
   const API_KEY = "your_api_key_here";
   ```
3. Open `index.html` in your browser (or use VS Code's Live Server extension)
